DISCGOLF SCORE – GRATIS WEBBAPP

Funktioner:
- 6, 9, 12 eller 18 hål
- Valfritt antal spelare
- Par per hål kan ändras under rundan
- Automatisk summering mot par
- Resultattavla och delning
- Historik sparas lokalt i telefonen
- Kan fungera offline när den publicerats på en webbserver

Testa på dator:
1. Öppna mappen i en enkel lokal webbserver.
2. Exempel med Python: python3 -m http.server 8000
3. Öppna http://localhost:8000

Gratis publicering:
Ladda upp mappens filer till GitHub Pages, Netlify eller Cloudflare Pages.
På iPhone: öppna länken i Safari, tryck Dela och välj "Lägg till på hemskärmen".
