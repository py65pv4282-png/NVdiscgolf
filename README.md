# Norra Vare Disc Golf – version 2

Färdig mobilanpassad PWA med:

- startsida för Norra Vare Disc Golf
- banguide för hål 1 och 2
- kartbilder, par, längd, beskrivning och speltips
- scorekort för 1–6 spelare
- automatisk summering mot par
- lokal historik
- offline-stöd via service worker
- installation på hemskärmen

## Publicera på GitHub Pages

Ersätt filerna i roten av repositoryt med filerna i detta paket.  
Mappen `assets` ska också laddas upp med samtliga filer.

Efter uppladdningen kan GitHub Pages behöva någon minut innan den nya versionen syns.
På iPhone kan Safari ibland visa en gammal cache. Ladda om sidan eller stäng och öppna Safari igen.
